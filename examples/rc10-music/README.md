# RC10 music demo

A demo for the Celoxica RC10 (XC3S1500): it plays three public-domain tunes
with a melody, bass line and drums on the stereo audio outputs. The LEDs are a
level meter and the 7-segment displays show patterns.

| Joystick | Action |
|---|---|
| left / right | previous / next tune: *Ode to Joy*, *Twinkle Twinkle Little Star*, *Frère Jacques* (shows `t1`–`t3`) |
| up / down | display mode: snake, note name (e.g. `E5`), VU columns, sparkle |
| centre | pause / play (shows `PA`) |

```sh
fpgaflow sim              # self-checking testbench (Verilator; --tool icarus works too)
fpgaflow build            # Yosys + ISE, 48 MHz clock, timing met
fpgaflow program          # load over the RC10's USB port (volatile)
```

Plug headphones or powered speakers into the RC10's audio output.
Verified on an RC10 (2026-11-22): the tunes, note names and display
orientation are right.

## How it works

| Module | Job |
|---|---|
| `music_top` | power-on reset, 1 kHz and 48 kHz ticks, joystick controls |
| `sequencer` | steps through the tune ROM; 128 BPM, eighth-note grid |
| `tunes`, `note_table` | tune ROM and 32-bit DDS increments, generated by `tools/gen_tables.py` |
| `synth` | plucked 25 % pulse melody, triangle bass, swept-triangle kick, noise snare and hi-hat (hi-hat louder on the right); envelopes `e -= e >> k` on the 1 kHz tick; 3-stage mix at 48 kHz |
| `sigma_delta` | 1st-order sigma-delta DAC per channel at 48 MHz into the board's RC filters |
| `level_meter` | peak level with 32 ms decay on 8 LEDs, log-ish steps |
| `segments` | the four display modes and the `tN` / `PA` overlays |

To change the music, edit the note lists in `tools/gen_tables.py` (note names
like `E5`, lengths in eighth notes, a bass note per melody note) and run it;
it rewrites `rtl/tunes.sv` and `rtl/note_table.sv`.

On the XC3S1500 it uses about 5 % of the slices and 4 of the 32 MULT18X18s,
and runs at up to 56.9 MHz against the 48 MHz clock.
